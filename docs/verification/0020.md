Sources, stated plainly:

- What ships is **Greenhouse boards, configurable as a list** (`GREENHOUSE_BOARDS`,
  comma-separated; `GREENHOUSE_BOARD` still works for one) plus the deterministic
  demonstration source. Greenhouse returns the employer's original description and a
  canonical URL, which is what "a source that stably yields the original JD" means.
- **104 was investigated and is not shipped.** It is reachable from the developer's
  agent tooling through an MCP server, but not from the Local Workspace server that
  runs this product, and there is no credential-free public contract the application
  can depend on. Nothing in the interface claims 104 coverage.
- This is a narrower answer than "coverage of the Taiwan job market", and the
  interface must not imply otherwise.

Limits and what is **not** verified:

- The demonstration curator returns fixed wording and reads no resume. It proves the
  at-most-five rule, the four-part shape and the validator, and is **no evidence at
  all** about whether a real model picks the right five jobs or describes the fit
  usefully. **Pending human validation with a configured provider and a real board.**
- Whether the recognised Taiwan and remote vocabulary is wide enough for real
  postings is a judgement against live data, not a code assertion.
- Salary is stored and displayed as the learner's own words; it is not parsed or used
  for filtering.
- The curation call sends the resume to the configured language model — the same one
  that already receives it for question generation — and this is disclosed. The
  confirmed rule "對外搜尋使用必要關鍵字" governs the job board, which receives
  profile terms only.
