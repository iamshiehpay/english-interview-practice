## 自動與實際操作證據

- `npm test`：78/78 通過。
- `npm run test:browser`：隔離工作區測試履歷預設／取消、第一次回饋、選擇再答、英文協助不算作答、單次作答結束、草稿失敗／重新載入、回饋失敗重試、手機無水平溢位。亦通過鍵盤 Enter 導覽、先 A 慢後 B 快的連續履歷辨識、有效檔案後選超大檔案不鎖住表單、修改草稿可返回結束且保留未評分內容，以及背景回饋失敗不清除新题草稿。
- `test/personalized-practice.test.js`：版本凍結、未提交草稿保留、AI協助獨立／快取、取消與刪除隔離、PDF／DOCX 真實本機擷取。
- `npm run evaluate`：v3 合成 fake 60/60 自動流程通過；固定 fake 評分不代表真實模型品質。

## 審查發現與處理

獨立規格／風險審查指出：開始修改後不能返回結束、兩段不同引文被當成差異、示範旁缺原文、連續上傳時舊結果覆蓋新檔，以及超大檔案使辨識鎖無法解除。已加入返回回饋、未提交草稿歸檔、真實字串差異、同區原文與上傳批次／畫面版本守衛，並補上瀏覽器回歸。

首次真實模型審閱發現未記載合作／收到回饋經驗的預設、英文改寫混入模型評語、中文想法轉英文漏掉未使用某技術的限制。初次輸出保存於 `evaluation/v3/personalized-live-initial.json`；契約已收緊，最終重验另存 `personalized-live.json`。

## 界線

- PDF 使用 `pdftotext`、DOCX 使用 macOS `textutil`，上傳最多 5 MB、辨識文字最多 50,000 字。掃描圖片 PDF 尚無 OCR，可改貼文字。
- 從履歷出題與英文改寫仍需使用者判斷內容是否符合自身情況；數字 guard 不能證明所有語義都無新增事實。
- v3 的針對性真實模型測試不是舊版 60 份、三輪穩定度驗證的替代；舊版 100%／98.75% 結果不能套用到新契約。
- 人工標註與五次真人練習仍待完成，沒有將合成資料或瀏覽器操作計入。
- 專案不是 Git repository，未 commit 或 push。
