## Limits

Natural-language content can violate semantic instructions even when structurally valid; strict schema and citation checks do not prove that all prose is free of answer leakage. Live provider evaluation belongs to subsequent integration/evaluation work. Atomic JSON storage supports one process per workspace, documented in README. No Git repository is configured.
