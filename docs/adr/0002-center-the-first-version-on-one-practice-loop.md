# Center the first version on one complete Practice Loop

The first version will optimize for a 15–20 minute Practice Loop: answer one job-specific question, receive transcript-grounded feedback on relevance, structure, and English expression, revise once, compare the attempts, and retain one weakness. Full courses, leaderboards, vocabulary systems, and broad long-term study plans remain outside the initial core so the product can first prove measurable improvement within one session.
