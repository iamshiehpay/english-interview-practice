# Cover four interview question categories in the MVP

The MVP will generate role-fit and motivation, experience and project-depth, behavioral and situational, and technical-communication questions. It will not execute coding challenges, grade source code, provide a whiteboard system-design environment, handle salary negotiation, or score pronunciation. The Feedback Report's support dimension adapts to the Question Category so a technical or Experience Gap answer can be supported by reasoning, assumptions, examples, and trade-offs rather than requiring a personal STAR story.
