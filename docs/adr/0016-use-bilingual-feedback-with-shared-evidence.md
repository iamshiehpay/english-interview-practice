# Use bilingual feedback with shared ratings and source evidence

The Target Learner needs Traditional Chinese explanations while practising English expression, so each Feedback Report presents Chinese then English for each finding and rating rationale, using one shared set of ratings and original transcript quotations. We choose paired explanations over an English-only report or two independently scored reports to support comprehension without making the assessment depend on display language; translations never replace source evidence.

This extends ADR0006 without changing its four-level rubric or reference-answer gate. The change affects provider output contracts, saved-data compatibility and evaluation: preserve existing single-language records and validate new bilingual output and semantic consistency; do not credit previous model evaluations as evidence for the changed contract.
