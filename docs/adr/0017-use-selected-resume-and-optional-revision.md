# Use a selected resume and make revision optional

A learner-selected resume is optional context for JD-grounded questions, without per-claim approval. Freeze its selected text and identity with each new job snapshot so replacement affects future practice only; treat supplied claims as background, not verified accomplishments. This replaces the approval-based personalization mechanism described historically in ADR 0009 and narrows ADR 0010: JD coverage remains independent of experience, but resume context may shape question wording.

One submitted answer with feedback is enough to end a practice loop. Revision is optional, and an on-demand English rewrite may be requested after the first feedback. Assistance is stored separately from learner attempts and never overwrites them. This supersedes the mandatory two-attempt completion/reference timing in ADR 0002 and the old UI plan; it preserves source facts and exact answer quotations.
