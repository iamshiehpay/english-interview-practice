# 中文引導與單題練習 UI 改版規劃

> 2026-09-18 更新：履歷個人化、選用第二次作答、首次回饋後可看英文示範及 headspace-meditation 視覺，依[最新試行決策](learner-flow-discussion.md)與[ADR 0017](adr/0017-use-selected-resume-and-optional-revision.md)實施。下文舊版強制雙次作答、逐項經驗核准及參考時機的描述已由新決策取代；人工標註與五次真人練習仍未完成。

狀態：本次中文引導與單題文字練習改版已完成實作及驗收。測試、瀏覽器流程、模型穩定度與雙語語義審閱證據見[改版驗證文件](verification/ui-redesign.md)。Issue 0008 人工標註與五次真人練習仍待完成；此處不宣告 MVP release 通過。

## 目標與範圍

讓使用者不需理解內部資料名稱，就能從職缺開始，完成同一題的初答、回饋、修訂、比較及保存。本次先做好文字練習；未配置真實語音時不顯示可操作的錄音入口。這是交付順序的決定，不撤銷ADR0005的長期語音優先方向。

不新增完整多輪面試、追問引擎、難度升降、倒數計時或虛擬人物。既有找職缺、履歷證據、歷史與進步仍可使用，但移至獨立入口。Issue0008的人工標註及五次親自練習不由本次改版替代。

## 已確認決策

| 項目 | 決策 |
|---|---|
| 操作語言 | 繁體中文；題目英文，中文題意主動展開；JD與引用保留原文 |
| 回饋語言 | 每個重點先繁中、再英文，同時顯示；共用評分與原文引文，引文只列一次 |
| 首次使用 | 貼JD → 產生練習題；先保存職缺，再產題，直接顯示推薦一題 |
| 題目選擇 | 推薦一題，保留換一題／查看全部；換題從既有題組取題，不暗中重新生成 |
| 回訪 | 優先繼續最近未完成練習，也可開始新練習或查看歷史 |
| 草稿 | 本機自動保存，切題後可回來繼續；未送出不算正式作答或完成 |
| 困難引導 | 主動展開思考提示／沒有相關經驗引導；提供結構，不提供完整代答 |
| 送出 | 一個「送出並取得回饋」按鈕；先保存回答，再請求模型 |
| 回饋密度 | 預設一項優點與一項優先改進，各中英對照；四項評分展開查看 |
| 完成 | 比較兩版後，預填可修改的下次練習重點，確認後保存 |
| 視覺 | 淡色、安靜清楚的單題頁；步驟列與明確主按鈕，適配手機 |

## 低保真畫面草圖

以下為版面示意；英文題目及文案均為例子，不表示新增一組正式練習紀錄。

### 首頁／準備職缺

```text
英文面試練習        練習紀錄  我的進步  我的經驗  找職缺  設定

繼續上次練習                        ← 僅有未完成練習時顯示
AI Application Engineer · 等待修改回答
[繼續練習]

開始新練習
你想準備哪個職缺？
[貼上職缺描述                                      ]
[                                                  ]
使用 Codex 訂閱生成題目；將傳送這份職缺內容。 查看資料說明
[產生練習題]
```

無歷史時不放空白的繼續卡。多筆未完成時首頁只突出最近一筆，其餘在練習紀錄可找到。新增職缺不覆寫既有職缺。

### 推薦題／第一次回答

```text
準備職缺 ✓ → 選題 → 回答與修改 → 比較與保存
AI Application Engineer                         [查看職缺]

建議先練｜技術說明
How would you check whether an AI-generated answer is reliable?
▸ 查看中文題意
為什麼推薦：這份職缺要求驗證答案品質與來源引用。
▸ 查看出題依據

[開始回答]     換一題     查看全部（10）

開始回答後：
你的英文回答
[                                                  ]
已儲存草稿                         ← 真正保存成功才顯示
▸ 給我思考提示     ▸ 我沒有相關經驗
[送出並取得回饋]
```

選題與作答同屬單題頁，按開始回答後展開作答區並移動焦點。英文題目一直可見。查看全部以題型分類，標示練過／未練，不重複展開每題原文證據。推薦理由須忠於實際推薦規則，不以能力不足或公司實際考題作無根據宣稱。

### 回饋／修改回答

```text
準備職缺 ✓ → 選題 ✓ → 回答與修改 → 比較與保存

本次做得好的地方
中文評語
English feedback
你的原句：“…”

這次優先改進
中文評語
English feedback
你的原句：“…”
▸ 查看四項評分與理由

修改你的回答
[預填第一次回答，修改的是新草稿，不覆寫初答            ]
已儲存草稿
[送出修改並取得回饋]
```

四項評分為切題程度、論據與例子、回答結構、英文表達，沿用既有四級語義；理由也中英對照。技術或假設題的論據可為推理、假設、例子與取捨，不強迫套個人經歷。提示不得憑空補充成就；展開提示不解鎖完整參考表達。

### 比較／保存

```text
準備職缺 ✓ → 選題 ✓ → 回答與修改 ✓ → 比較與保存

看看這次改變了什麼
第一次回答與回饋              修改後回答與回饋
[原回答]                      [修改回答]
[可展開評分與原句]            [可展開評分與原句]
                           手機改為上下排列，標示清楚

下次練習重點
[預填優先改進建議，可修改                            ]
[儲存本次練習]
▸ 查看參考表達                  ← 第二次回饋完成後才可用
```

比較不得預設一定進步，也不可只顯示分數箭頭；維持原文與證據可查。Focus Point預填中文優先改進，學習者可修改；不因翻譯相似就自動合併歷史進步項目。

## 狀態與恢復規則

| 情境 | 可見行為與資料規則 |
|---|---|
| 空白JD | 就地說明需貼職缺內容，不建立空紀錄 |
| 保存職缺／產題中 | 顯示實際步驟，不虛構百分比；防止重複送出；外部請求可取消 |
| 產題失敗 | 保留已保存JD，原位置提供重試，不要求重新貼上 |
| 換題／離開頁面 | 保存目前草稿；同題可恢復。保存失敗明確提示並攔截應用內切換，不能假裝已保存 |
| 瀏覽器強制終止 | 草稿僅承諾恢復最後一次成功保存的內容；不宣稱最後一個按鍵必然存妥 |
| 回饋中 | 回答已保存，禁止重複提交；可取消。切換頁面不視為自動取消 |
| 回饋失敗／取消 | 已提交回答保留，重試只取得該回答的回饋，不新增重複attempt |
| 修改回答 | 建立第二次回答草稿，不改寫第一次回答；第一次回饋成功後才可送出修訂 |
| 刪除紀錄／全部資料 | 一併移除相應文字草稿，取消相關操作；晚到回應不能復活已刪資料 |
| 舊單語紀錄 | 原內容完整保留，清楚標示舊版回饋；不得以雙語占位假裝已翻譯，不自動付費重評歷史 |
| 未登入／未驗證 | 指引到設定，不讓使用者先寫完才知道無法請求；仍保留本機草稿 |

自動保存資料應納入既有可刪除的本機工作區，不能變成使用者刪除全部後仍存在的隱藏副本。原先語音轉錄草稿和自行輸入的作答草稿概念不同，不可混用。

## 實作順序（已授權）

1. 先以此草圖確認資訊層級；不重做已確定的產品選項。
2. 雙語資料契約：題目中文題意、中文推薦說明及中英回饋；維持原文引用、固定評分、舊資料讀取。修改需涵蓋fake／API／Codex providers、驗證器及評估工具，不能只翻按鈕。
3. 文字草稿與恢復：區分草稿與正式回答，完成自動保存、刪除、一致性及失敗處理。
4. 分階段介面與中文文案：導覽、推薦題、提示、單一送出動作、雙語回饋、比較及保存。
5. 完整瀏覽器驗證及provider回歸；獨立review後再記錄改版驗收。

## 驗收清單

- [x] 初次不需填履歷或讀完整能力分析，即能從JD進入推薦题。
- [x] 回訪可繼續最近未完成練習；其他紀錄及新練習仍容易找到。
- [x] 換題與查看全部保留8–12題集合及歷史；單純切題不新增模型呼叫。
- [x] 非英文練習內容的操作文案為繁中；英文題目可展開中文題意，引用保持原文。
- [x] 每項回饋中英同時呈現、共用評分及原句；不得出現兩種語言相互矛盾的建議。
- [x] 首頁與作答頁不再堆疊能力清單及重複JD引文；事實／推論仍可辨識。
- [x] 草稿切題／重新整理可恢復，保存失敗不誤導；初答不被修改草稿覆寫。
- [x] 送出先保存後取回饋；取消、失敗、重試不丟回答、不新增重複紀錄。
- [x] 提示不造假經驗、不提早解鎖完整參考表達；Experience Gap可正常完成。
- [x] 比較保留兩版原文，Focus Point可修改並確認保存；草稿不算完成。
- [x] 舊工作區及舊單語回饋仍可讀；刪除涵蓋新草稿。
- [x] 手機單欄、桌面合理行寬、鍵盤操作、焦點、狀態通知與對比度均經檢查。
- [x] 自動測試涵蓋新的雙語契約與恢復規則；瀏覽器走完新主流程及至少一次失敗恢復。
- [x] 新prompt／schema版本重跑實質模型穩定度及雙語語義檢查；既有98.75%結果只代表舊版本，舊人工標註若不再對應輸入須重新審閱。
