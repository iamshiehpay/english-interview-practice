# Triage labels

The local tracker uses these status values:

| Canonical role | Local value |
| --- | --- |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

Completed work may use `completed`; work awaiting non-automatable validation may use `awaiting-human-validation`.
