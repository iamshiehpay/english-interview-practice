# Agent guidance

## Agent skills

### Issue tracker

Issues are tracked as local Markdown files in `docs/issues/`; external pull requests are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five triage labels are recorded as Markdown status values. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context project: read the root `CONTEXT.md` and relevant `docs/adr/` decisions before changing product behaviour. See `docs/agents/domain.md`.
